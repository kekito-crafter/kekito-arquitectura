Así funciona Kekito

Un bot de WhatsApp que recibe mensajes en grupos, decide qué hacer y responde con texto, voz, stickers, páginas web y más.

Respuesta
💬

Mensajes

WhatsApp llega mediante wapi, una API autohospedada. El mensaje entra por un webhook firmado; se confirma rápido y luego se procesa.

🧠

El cerebro

La app está hecha con Next.js, React y TypeScript. Usa un modelo de OpenAI mediante Vercel AI SDK para entender pedidos y redactar respuestas.

🔊

Cómo genera audios

Convierte el texto a voz con gpt-4o-mini-tts. Después ffmpeg lo transforma a Ogg/Opus mono a 48 kHz para que WhatsApp lo reproduzca como nota de voz.

🖼️

Cómo manda stickers

Parte de una imagen, GIF o video. ffmpeg lo adapta a WebP de 512×512; si se mueve, genera WebP animado. Luego wapi lo envía al grupo.

🌐

Cómo crea webs

Puede crear un repositorio en GitHub, subir archivos como index.html en un commit y activar GitHub Pages para publicarlo.

🚀

Despliegue

Corre en un contenedor Docker en un VPS administrado por Dokploy, detrás de Traefik y HTTPS con Let's Encrypt.

🗃️

Memoria y servicios

Notas, historial por chat y biblioteca de stickers viven en Postgres. Redis y almacenamiento de objetos apoyan a wapi. La sesión de WhatsApp también se guarda en la base de datos, así los redeploys pueden reconectar sin pedir QR de nuevo.

El recorrido completo

  1. Alguien etiqueta a Kekito en un grupo.
  2. wapi recibe el evento de WhatsApp y lo entrega por webhook.
  3. La app interpreta el pedido, usa herramientas si hacen falta y prepara el resultado.
  4. Si es voz o sticker, convierte el archivo al formato compatible.
  5. wapi pone la respuesta en la cola y WhatsApp la entrega.
